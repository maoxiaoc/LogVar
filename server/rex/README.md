# Rex 使用 LogVar 通用弹幕模块

当前版本 **1.0.17**，与 Forward 使用同一份 [logvar-1.0.17.js](../dist/logvar-1.0.17.js)。

- [JS 原文导入链接](https://raw.githubusercontent.com/maoxiaoc/LogVar/main/server/dist/logvar-1.0.17.js)
- [1.0.7 → 1.0.17 完整更新对照](../forward/CHANGELOG.md)
- [配置、缓存、来源标签、加载时间与构建说明](../forward/README.md)

在 Rex 模块管理中停用旧 Rex 独立模块，导入通用文件，按需重新填写配置。启用 LogVar，执行“清理弹幕缓存”，再搜索作品并选择分集。两个播放器各自保存配置和缓存。

本次包含移除爱壹帆（默认 9 个改为 8 个来源）、去重数字输入、自动缓存及完整清理、策略切换结果和来源标签修复、爱奇艺无计时器备用请求，以及加载预算和耗时记录。1.0.17 已移除“检测完整弹幕流程”入口及函数。

无计时器或宿主不执行 HTTP 超时参数时，仍不能保证严格的 5／10／30 秒上限。模块无法主动更新已打开页面的来源文字，需要重新搜索选集。详见通用说明。
